\subsection{A Posteriori Error Estimation via Self-Convergence}
\label{seq:self_convergence}

The accuracy studies above rely on a sequential reference solution, which is
unavailable in production---computing it would negate the parallel speedup.
\method\ can instead estimate its own truncation error, for the following
reason. Let $u^{(0)}$ denote the truncated parallel solution of
\cref{eq:truncated_form}. By \cref{eq:global_error_sum}, its error is not an
unknown quantity: it is \emph{exactly} the sum of the omitted thermal tails
$v_{i\to j}$, each of which the solver is able to compute. Suppose the
omitted tails are recovered in batches: iteration $k$ computes one further
batch and superposes it, producing a refined iterate $u^{(k)}$ with increment
$d_k = u^{(k)} - u^{(k-1)}$. Since every omitted tail appears in exactly one
batch, \cref{eq:global_error_sum} telescopes into
\begin{equation}
u^{\mathrm{exact}} - u^{(0)} \;=\; \sum_{k\ge 1} d_k .
\label{eq:telescoping}
\end{equation}
(Predecessors never connected in the DAG remain excluded; their
contributions are below the calibrated threshold by \cref{eq:edge_criterion}
and were negligible in all our experiments.) The increments are therefore
not mere indicators of convergence---they are the missing pieces of the
error itself, and summing what has been measured reconstructs the error that
was made: $\|u^{(k)} - u^{(0)}\|$ converges to
the true error of $u^{(0)}$ with no reference solution involved. The series
converges quickly because later batches contain tails at larger elapsed
times, which the contractive source-off evolution
(\cref{eq:stability_contraction}) attenuates; the decay of $\|d_k\|$ thus
signals that the sum is complete, and the iteration stops once $\|d_k\|$
falls below the accuracy target. Finally, the procedure repairs what it
measures: $u^{(k)}$ is itself a more accurate solution, so a run that
detects a tolerance violation has already computed its remedy.

In practice each batch is realized by extending the correction window of
every retained dependency by $\Delta$ segments and evaluating the omitted
tails on the newly exposed window with the source-off operator
(\cref{eq:correction_recursion}); no source-on solve is repeated and no DAG
is rebuilt. All norms below are the relative $L^2$ metric of
\cref{seq:accuracy}, maximized over the sampled snapshots.

We validate the estimator on the Bull path with the $10^{-4}$ configuration
of \cref{tab:acc_1e4}, partitioned across 32 ranks, where the many partition
boundaries drive the observed error slightly above the target.
\cref{tab:self_convergence} reports six iterations with $\Delta = 4$: the
increments decay monotonically, each $\|d_k\|$ reproduces the true error of
the previous iterate to three or more significant digits, and the converged
estimate $\|u^{(6)} - u^{(0)}\| = 1.0767\times10^{-4}$ equals the true
production error to all reported digits. One iteration restores the run to
its target; six reduce the error by three orders of magnitude.
